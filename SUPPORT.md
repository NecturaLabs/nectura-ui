# Getting help

- **Something is broken or missing**: search the
  [open issues](https://github.com/NecturaLabs/nectura-ui/issues) first, then file one with the bug
  or feature form. Include the commit you use, your egui and Rust versions, your operating system
  and the steps that show it.
- **A question about using the library**: the [README](README.md) shows how to add it and start
  it; the component gallery (`kit::gallery::show`) shows every component. If that does not answer
  it, ask in a [Canopy discussion](https://github.com/NecturaLabs/Canopy/discussions), where
  questions about NecturaLabs' libraries are welcome too.
- **A security problem**: never in a public issue. Follow [SECURITY.md](SECURITY.md).
- **Behaviour in project spaces**: see the [code of conduct](CODE_OF_CONDUCT.md).
